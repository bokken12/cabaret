File pages (diff, review, workspace) open with a heading: the change's name and which files these are. Its text links to the first file listed, so Enter there starts reading the view top to bottom with `$`. Being a link rather than a row, selections skip it. Enter on a folder opens every file under it in one multi-file diff. The file targets now carry a list of files: one for a file's row, everything under a folder for the folder's row. Selections take in every file their rows lead to, without duplicates, so `! m` and `! c` on a folder act on the whole folder.
