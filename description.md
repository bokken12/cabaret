With refusals carrying the widened Safeguard, per-action safeguard types had nothing left to do: the safeguards! macro and its XSafeguard enums and XAllow structs go, replaced by one Allow(BTreeSet<SafeguardKind>) whose check refuses the safeguards not allowed.

The CLI's per-command --allow-<kind> flags become one repeatable --allow <kind>, whose possible values are every SafeguardKind, so a refusal's hint parses on every command by construction. Lost: per-flag help text, the archive/unarchive split of which flags go with --undo, and rejecting kinds an action never checks (node's 'nothing to allow' error).
