`cab fetch` exchanges branches with origin as well as logs. The synced branches are origin's default branch (as its HEAD advertises) and those of unarchived changes with a log. Each one is created from origin's when missing locally, fast-forwarded when behind, and pushed (never forced) when origin is behind. A synced branch that has diverged from origin's, or whose workspace's local changes would conflict with origin's, is left as it is and reported: the CLI prints `kept <change>: <why>`. Other branches are still only fetched as `refs/remotes/origin/*`, so stale or private local branches are never published, and archived changes' branches are never pushed, so a landed and deleted branch doesn't come back.
