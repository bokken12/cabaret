Preflight design for discouraged actions (sibling alternative: discouraged-refusal). Cabaret::land_concerns / rebase_concerns query the concerns up front; VSCode folds them into the land confirm modal (and a new rebase modal), then passes the shown reasons as even_though. The action still re-checks in its transaction, so a concern arising in between refuses with the base change's message. Trade-off: in a multi-change sequence, later changes' concerns are computed before earlier ones land.
