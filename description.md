Parse what the active tab shows once per command into an `Active` union (a page with its route and rendered `Page`, a tab of file diffs with the focused one, a description, a workspace file, or other) and hand it to each command, instead of every command and helper sniffing the active editor, tab and URI scheme itself through `activePage`, `activeFilesDiff`, `focusedFileDiff` and `impliedChange`. `updatePageContext` becomes a projection of the same value, so keybinding context and command behaviour can no longer disagree.

Behaviour changes: a page shown without having been rendered is now an error rather than silently selecting nothing; and every command parses the tab up front, so an inconsistent multi-file diff tab errors even for commands that ignore it. `refresh` and `step`'s post-picker row lookup still read afresh, since the user may have moved on while an input was open.
