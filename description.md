A cabaret-forge crate, with no network yet: the GraphQL query for a GitHub pull request's history, lenient types for its response, and the reading of that history as the events importing records. Opening is the first event, under the pull request's own id; GitHub keeps no event for it, so how it began is read back from the first event to change each field. Tested against two responses GitHub gave for this repository, logins replaced, and one written by hand for the rest.
