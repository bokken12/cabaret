Add `cab change endorse [--undo]`: an owner's approval of a change as a whole, recorded as Endorse/Unendorse log actions. Unlike file review it holds however the change evolves. Endorsing with files left to review is refused (`unreviewed`); landing until every owner has endorsed is refused (`unendorsed`). The show page lists endorsers and names endorsement as a next step after review. VS Code toggles it with `!e`.
