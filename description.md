Enter over a selection on a diff, review or workspace page opens the selected files in VS Code's multi-file diff. On that diff, `! m` marks every file, `d`/`r` switch view keeping the files, Escape returns to the page, `^`/`$` step past the first/last file, and Enter opens the focused file. Relies on the unpublished `tabInputMultiDiff` typings (vendored); VS Code already exposes the input at runtime.
