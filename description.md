Show diff contents from `cab change diff` and `cab change review` when given pathspecs; with none they still list files. The lib's `view_diff` names the revisions holding both sides of each file, read in one transaction, and `blob` reads a side's bytes and mode. The CLI renders them as git-compatible unified diffs via gix, headed by the tip to `mark --tip` at; VS Code builds its diff editors from the same `view_diff` instead of assembling the sides itself.
