cab sync exports to GitHub after pushing: it carries out forge_exports, opening a pull request for a change up for review, or editing a pull request's title and base to match its change. It is off unless the repository sets cabaret.forge.export (cab config forge-export set true). A change that adds nothing to its parent is not opened, since GitHub refuses a pull request with no commits. Checked against a private scratch repository; there is no test of the GitHub calls themselves.
