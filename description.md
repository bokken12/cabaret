The GitHub client: it finds the repository from origin's URL, authenticates with GITHUB_TOKEN or else gh's token, lists pull requests by last update over REST, and fetches one pull request's history over GraphQL a page at a time. It uses octocrab with its optional features off, run to completion on a runtime of its own so nothing outside the crate is async. Nothing calls it yet. Paging has no test: no recorded pull request has more than one page of events.
