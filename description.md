File pages (diff, review, workspace) open with a heading: the change's name and which files these are. Its text links to the first file listed, so Enter there starts reading the view top to bottom with `$`. Being a link rather than a row, selections skip it. Enter on a folder opens every file under it in one multi-file diff. A new `DiffView` enum names the three diffs, so one `Target::Diff { view, change, files }` replaces the per-view targets, and `files_page` / `view_files` replace the per-view pages and file lists across lib, napi, CLI and extension. A file's row leads to that file and a folder's row to everything under it. Selections take in every file their rows lead to, without duplicates, so `! m` and `! c` on a folder act on the whole folder.
