Workspace safeguards: uncommitted, on workspace_remove (any local change, untracked included; allowing deletes them with it) and workspace_switch (changes to tracked files; allowing drops them, untracked files stay). The store drops them after the refs move, via Workspace::drop_local_changes, so a failed transaction loses nothing. workspace_remove_safeguards previews; VSCode names what deleting would discard in the land and delete dialogs, and asks again if refused.
