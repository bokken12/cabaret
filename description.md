File pages (diff, review, workspace) open with a heading: the change's name and which files these are. Enter on the heading opens the first file listed, so a view can be read top to bottom with `$`. Enter on a folder opens every file under it in one multi-file diff. The file targets now carry a list of files: one for a file's row, everything under a folder for the folder's row, and the first file for the heading. Selections take in every file their rows lead to, without duplicates, so `! m` and `! c` on a folder act on the whole folder.
