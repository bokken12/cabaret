cab sync imports GitHub pull request histories, after merging origin's logs and before pushing. It lists the pull requests changed since the time kept in git config as cabaret.forge.imported (those open, the first time), and imports each that is not from a fork and is either open or already has a log, deciding from the listing so that a skipped one costs no request of its own. It does nothing without a GitHub origin or a token. Stacked on sync-ignores-sigpipe, without which the CLI dies before reaching it.
